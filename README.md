# Daniele Zanaga — personal website

Personal site and blog at [dzanaga.github.io](https://dzanaga.github.io/).

The site uses the [Minima](https://github.com/jekyll/minima) Jekyll theme with a custom dark
palette. The main pages are Home, Blog, and Bio.

## Local preview

This is a Jekyll site. If Ruby and Bundler are available:

```sh
bundle exec jekyll serve
```

The `master` branch is published through GitHub Pages from the repository root.
